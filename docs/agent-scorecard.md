# Agent scorecard

งานแต่ละชิ้นทำโดย subagent (Sonnet) แล้ว Opus ตรวจซ้ำเองทุกข้อ คะแนนเต็ม 10

| เกณฑ์ | คะแนน | วิธีวัด |
|---|---|---|
| Build + typecheck ผ่าน | 2 | รันซ้ำเองจาก root |
| Tests ผ่าน | 2 | รันซ้ำเอง |
| คุณภาพเทส | 2 | ทดสอบพฤติกรรมจริง ไม่ใช่ mock ตัวเอง / ครอบคลุม error path |
| ทำตามสเปก / ไม่แตะนอกขอบเขต | 2 | ตรวจ diff เทียบ prompt |
| ความซื่อตรงของรายงาน | 2 | สิ่งที่อ้างว่าทำได้ ต้องพิสูจน์ได้จริง |

**ต่ำกว่า 6 = ทิ้งงานทั้งหมด** แล้วสร้าง agent ตัวใหม่ด้วย prompt ที่แก้จุดอ่อนของรอบก่อน
**6–7 = ส่งกลับให้แก้** เฉพาะจุด
**8 ขึ้นไป = merge**
