# Agent scorecard

งานแต่ละชิ้นทำโดย subagent (Sonnet) แล้ว Opus ตรวจซ้ำเองทุกข้อ คะแนนเต็ม 10

| เกณฑ์ | คะแนน | วิธีวัด |
|---|---|---|
| Build + typecheck ผ่าน | 2 | รันซ้ำเองจาก root |
| Tests ผ่าน | 2 | รันซ้ำเอง |
| คุณภาพเทส | 2 | ทดสอบพฤติกรรมจริง ไม่ใช่ mock ตัวเอง / ครอบคลุม error path |
| ทำตามสเปก / ไม่แตะนอกขอบเขต | 2 | ตรวจ diff เทียบ prompt |
| ความซื่อตรงของรายงาน | 2 | สิ่งที่อ้างว่าทำได้ ต้องพิสูจน์ได้จริง |

**ต่ำกว่า 6 = ทิ้งงานทั้งหมด** แล้วสร้าง agent ตัวใหม่ด้วย prompt ที่แก้จุดอ่อนของรอบก่อน
**6–7 = ส่งกลับให้แก้** เฉพาะจุด
**8 ขึ้นไป = merge**

## ผลรอบที่ 1

| งาน | Agent | คะแนน | ผล |
|---|---|---|---|
| packages/simulator | sonnet #1 | **9/10** | merge — 11/11 tests; Opus probe แยกด้วย client จริงยืนยันอ่าน/เขียนความสว่างข้าม connection ได้ (−1: ไฟล์เทสไม่ผ่าน typecheck) |
| apps/desktop | sonnet #3 | **9/10** | merge — 30/30 tests, build ผ่าน; Opus render ใน Chromium แล้ว UI ภาษาไทยแสดงถูก ไม่มี console error (−1: ยังไม่ได้เปิดใน Electron จริง) |
| packages/device | sonnet #2 | ไม่ให้คะแนน → **ทิ้ง** | ติดสิทธิ์ติดตั้ง `@novastar/native` — หยุดและรายงานตามจริง (พฤติกรรมถูกต้อง) ยังไม่มีโค้ด จึงลบทิ้ง |

## ผลรอบที่ 2

| งาน | Agent | คะแนน | ผล |
|---|---|---|---|
| packages/device | sonnet #4 (ตัวใหม่, prompt ปรับปรุง) | 7/10 → แก้แล้ว **8/10** | ส่งครั้งแรก: Opus ตรวจพบว่ารายงาน "ไม่มีคำสั่งจอดำ" ผิด (`SetKillMode`/`SetLockMode` มีอยู่) และ freeze ผูกกับคำสั่งผิดตัวด้วยการเดา → ส่งกลับแก้เฉพาะจุด → แก้ถูก 28/28 tests → merge (−2: วิจัยไลบรารีไม่ครบรอบแรก; ค่า byte จอดำ/หยุดภาพยังไม่ยืนยันกับเครื่องจริง) |
| ต่อหน้าจอเข้ากับการ์ดจริง | Opus (ทำเอง) | — | เพิ่ม backend `real` / `sim`; พบและแก้บั๊ก bundle ของ Electron main ที่ require แพ็กเกจที่หาไม่เจอ (เทสหน่วยจับไม่ได้) ; ทดสอบ bundle ที่ build จริงผ่าน IPC → device → TCP → simulator |

## ผลรอบที่ 3 (ระยะ 3–5, ทำพร้อมกัน 3 ตัวบน seam แยกไฟล์)

| งาน | Agent | คะแนน | ผล |
|---|---|---|---|
| ระยะ 3 การ์ดส่ง | sonnet #5 | **9/10** | merge — 32 tests ใหม่; Opus เทียบ address 7 คำสั่งกับไลบรารีตรงทุกตัว ไม่มี address แต่งเอง (−1: พอร์ตที่ไม่มีการ์ดไม่แสดง) |
| ระยะ 4 การ์ดรับ | sonnet #6 | **8/10** | merge — Opus เทียบ address + ความกว้าง byte 8 คำสั่งตรง, ยืนยันข้อ "ไม่มี refresh เป็น Hz" ด้วยการค้นซ้ำ (−2: ตั้งชื่อ "cabinet" ให้สิ่งที่จริง ๆ เป็นขนาดโมดูล — Opus เปลี่ยนชื่อเป็น module profile เอง) |
| ระยะ 5 ผังจอ | sonnet #7 | **9/10** | merge — Opus ยืนยันข้อที่ agent แจ้งว่าไลบรารีขัดกันเองเรื่องลำดับ X/Y เป็นความจริง และการเลือกตามฟังก์ชัน 2 ใน 3 ที่ตรงกันสมเหตุผล (−1: หมายเลขตู้ถูกจุดเริ่มสายบัง — Opus แก้เอง) |

สรุป: รอบนี้ไม่มีตัวไหนต้องทิ้ง ไม่มีการอ้าง "ไม่รองรับ" ที่ผิดเหมือนรอบก่อน — prompt ที่บังคับให้แจ้งคำค้นได้ผล
