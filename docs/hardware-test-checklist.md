# คู่มือทดสอบกับฮาร์ดแวร์จริง (RockzaLCT)

เอกสารนี้สำหรับเจ้าของเครื่อง ที่มี MCTRL300 / MCTRL660 / MCTRL700 และ VX400 / VX600 / VX1000 / VX2000 Pro (ต่อได้ทั้ง USB และ LAN)

**เหตุผลที่ต้องทดสอบ:** โค้ดถูกเขียนจากไลบรารี `@novastar/*` และทดสอบกับการ์ดจำลองเท่านั้น ยังไม่เคยคุยกับเครื่องจริง มีหลายค่าที่ "เดา" จากเอกสารไลบรารี (ระบุว่า UNVERIFIED ในโค้ด) งานของคุณคือบอกเราว่าค่าไหนถูก ค่าไหนผิด

เรียงลำดับจากปลอดภัยที่สุดไปเสี่ยงที่สุด **ทำทีละขั้น อย่ากระโดดข้าม และหยุดทันทีที่เจออะไรผิดปกติ**

---

## 0. ความปลอดภัย (อ่านก่อนเสมอ)

1. ทดสอบกับ **จอเล็กหรือชุดทดสอบ** ก่อน อย่าลองครั้งแรกกับจอที่ติดตั้งใช้งานจริงหรือจอที่ลูกค้ารออยู่
2. ขั้นที่ 1–10 เป็น **อ่านค่า/สั่งชั่วคราว** (ความสว่าง ภาพทดสอบ จอดำ/หยุดภาพ ไม่ต้องล็อกอินขั้นสูง และค่าจะหายเมื่อปิดไฟ) ขั้นที่ 11 เป็นต้นไป **เขียนค่าที่ต้องล็อกอินขั้นสูง** และขั้นที่ 12 **เขียนลงแฟลชถาวร**
3. **สำรองค่าก่อนเขียนทุกครั้ง:** เมนู **บันทึก/โหลด** → ส่วน **อ่านค่ากลับและบันทึกเป็นไฟล์** → กด **อ่านจากตัวควบคุม** → กด **บันทึกไฟล์ตั้งค่า…** เก็บไฟล์ `.json` ไว้หลายชุด (ตั้งชื่อตามรุ่นและวันที่) และถ่ายรูป/จดค่าของ NovaLCT เดิมที่ใช้งานอยู่ไว้ด้วย
4. ถ้าอ่านแล้วขึ้น "อ่านส่วนเหล่านี้ไม่สำเร็จ" หรือ "ข้อมูลที่อ่านได้ไม่ครบ" ไฟล์สำรองนั้น **ไม่สมบูรณ์** อย่าถือว่าเป็น backup
5. การเขียนต้อง **เข้าสู่ระบบขั้นสูง** (ปุ่ม **เข้าสู่ระบบขั้นสูง** มุมบน) รหัสผ่านเริ่มต้นของโปรแกรมคือ `admin` (โหมด `--mock` ใช้ `rockza`) ยังไม่ต้องล็อกอินจนกว่าจะถึงขั้นที่ 11
6. ห้ามถอดสาย USB/LAN หรือปิดไฟระหว่างที่โปรแกรมกำลัง "บันทึกลงฮาร์ดแวร์"
7. ถ้ามีตัวควบคุมหลายตัวในเครือข่ายเดียวกัน ให้ถอดตัวอื่นออกก่อน เพื่อไม่ให้เขียนผิดเครื่อง
8. ถ้าจอผิดปกติหลังการทดสอบ: ปิดไฟตัวควบคุมแล้วเปิดใหม่ (ค่าที่ยังไม่บันทึกลงแฟลชจะกลับเป็นค่าเดิม) หรือโหลดไฟล์ที่สำรองไว้ผ่านเมนู **บันทึก/โหลด** → **เปิดไฟล์ตั้งค่าและนำไปใช้**

---

## วิธีบันทึกผล

ทุกขั้นมีช่อง "ถ้าต่างจากที่คาด ให้จด" ให้จดลงตารางผลท้ายเอกสาร (หัวข้อ 14) พร้อมถ่ายภาพหน้าจอโปรแกรมและภาพจอ LED ถ้าเกี่ยวกับการแสดงผล แล้วส่งกลับมา

ข้อมูลที่ต้องแนบทุกครั้ง: รุ่นตัวควบคุม, รุ่นการ์ดรับ (ป้ายบนการ์ด), ช่องทางเชื่อมต่อ (USB/LAN), เวอร์ชันโปรแกรม (`RockzaLCT-Setup-x.y.z.exe`)

---

## 1. ติดตั้งโปรแกรม

1. ดาวน์โหลด `RockzaLCT-Setup-<เวอร์ชัน>.exe` (จากหน้า Releases หรือ Actions → Artifacts ของ GitHub)
2. Windows SmartScreen อาจเตือน "unknown publisher" เพราะไม่ได้เซ็นดิจิทัล เลือก **More info → Run anyway**
3. ติดตั้งแล้วเปิดโปรแกรม **RockzaLCT**

**คาดว่า:** หน้าต่างภาษาไทยเปิดขึ้น เมนูซ้าย: การเชื่อมต่อ, ความสว่าง, ทดสอบและการแสดงผล, การ์ดส่ง, การ์ดรับ, ผังการเชื่อมต่อจอ, บันทึก/โหลด, ตรวจสอบสถานะ แถบบนแสดง **ยังไม่ได้เชื่อมต่อ**

**ลองโหมดจำลองก่อน (ไม่ต้องมีฮาร์ดแวร์):** สร้างทางลัดของโปรแกรมแล้วเติม ` --sim` ท้ายช่อง Target (เช่น `"C:\Users\<ชื่อ>\AppData\Local\Programs\RockzaLCT\RockzaLCT.exe" --sim`) หรือรันจาก PowerShell แล้วกดค้นหา ควรเจอตัวควบคุมจำลอง ถ้าใช้ได้แสดงว่าตัวติดตั้งสมบูรณ์ **การเปิดแบบปกติ (ไม่มี `--sim`) คือโหมดต่อเครื่องจริง**

**ถ้าเปิดไม่ขึ้น/ขึ้น error เกี่ยวกับ serialport:** จดข้อความทั้งหมด ถ่ายภาพ และหยุดทดสอบ (เป็นปัญหาของตัวติดตั้ง)

---

## 2. เชื่อมต่อทาง USB

1. ต่อสาย USB จากตัวควบคุมเข้าคอมพิวเตอร์ เปิดไฟตัวควบคุม รอให้ Windows ติดตั้งไดรเวอร์ (ดูใน Device Manager ว่ามี COM port ใหม่ — **จดหมายเลข COM**)
2. ปิด NovaLCT เดิมและโปรแกรมอื่นที่ใช้พอร์ต COM นั้นอยู่ (ใช้พร้อมกันไม่ได้)
3. เมนู **การเชื่อมต่อ** → กด **ค้นหา**
4. ในตาราง **ตัวควบคุมที่พบ** หาแถวประเภท **อนุกรม (USB/COM)** → กด **เชื่อมต่อ**

**คาดว่า:** พบตัวควบคุม แถบบนเปลี่ยนเป็น **เชื่อมต่อแล้ว: <ชื่อ>** มีกล่อง **ตัวควบคุมที่เชื่อมต่ออยู่**

**จดถ้าต่าง:** ไม่พบเลย / พบแต่เชื่อมไม่ได้ / ข้อความ error (เช่น `ตัวควบคุมไม่ตอบสนองภายในเวลาที่กำหนด`, `การสื่อสารกับตัวควบคุมผิดพลาด`) / มีหลาย COM แล้วเลือกผิด / ค้างนานเท่าไร

กด **ตัดการเชื่อมต่อ** ก่อนทดสอบช่องทางถัดไป

---

## 3. เชื่อมต่อทาง LAN

1. ต่อสาย LAN จากตัวควบคุม (หรือผ่านสวิตช์) เข้าเครือข่ายเดียวกับคอมพิวเตอร์ ตั้ง IP คอมพิวเตอร์ให้อยู่วงเดียวกับตัวควบคุม (ตรวจ IP ของตัวควบคุมจากเครื่องมือเดิม/คู่มือ) พอร์ตเริ่มต้นของโปรแกรมคือ 5200
2. เมนู **การเชื่อมต่อ** ช่อง **โฮสต์เครือข่าย (ไม่บังคับ คั่นด้วยเครื่องหมายจุลภาค)** ใส่เช่น `192.168.0.10` หรือ `192.168.0.10:5200` (ใส่หลายเครื่องคั่นด้วย `,`)
3. กด **ค้นหา** → แถวประเภท **เครือข่าย (LAN)** → **เชื่อมต่อ**
4. Windows Firewall อาจถามสิทธิ์ ให้อนุญาตบนเครือข่ายส่วนตัว

**จดถ้าต่าง:** ไม่พบ / ใช้พอร์ตอื่นที่ไม่ใช่ 5200 หรือไม่ / เชื่อมสำเร็จแต่ข้อมูลต่างจาก USB หรือไม่ / อ่านค่าช้ากว่า USB มากหรือไม่

---

## 4. อ่านข้อมูลอุปกรณ์ (อ่านอย่างเดียว)

เมนู **การเชื่อมต่อ** → กล่อง **ตัวควบคุมที่เชื่อมต่ออยู่** ดูช่อง **รุ่น**, **เฟิร์มแวร์**, **พอร์ตเอาต์พุต**, **การ์ดรับ** (ตารางคอลัมน์ พอร์ต / การ์ดที่ / รุ่น / เฟิร์มแวร์)

**คาดว่า:**
- **รุ่น** จะแสดงเป็น `Unknown (0x....)` เพราะไลบรารีไม่มีตารางชื่อรุ่น — **นี่คือสิ่งที่ต้องการ: จดเลข 0x.... ให้ตรงกับรุ่นจริงที่เป็นเจ้าของ** (เช่น MCTRL660 → 0x????) ทุกเครื่อง เราจะใช้ทำตารางชื่อรุ่น
- **เฟิร์มแวร์** รูปแบบ `a.b.c` (หรือ `a.b.c.d`) เทียบกับเวอร์ชันใน NovaLCT เดิมว่าตรงกันหรือไม่
- **พอร์ตเอาต์พุต** ตรงกับจำนวนพอร์ตจริงของรุ่น (ตรวจตามคู่มือเครื่องของรุ่นนั้น)
- **การ์ดรับ** จำนวนตรงกับที่ต่ออยู่จริงหรือไม่ ถ้าไม่ตรงให้จดพอร์ตที่ขาด/เกิน

**จดถ้าต่าง:** model id (0x....) ของแต่ละรุ่น, เฟิร์มแวร์ที่ไม่ตรงกับ NovaLCT, จำนวนพอร์ต/การ์ดที่ผิด

---

## 5. ความสว่าง (เขียนชั่วคราว ความเสี่ยงต่ำ)

เมนู **ความสว่าง**: ตัวเลื่อน **ความสว่างรวม**, **เกนสีแดง / เขียว / น้ำเงิน**, ปุ่ม **นำไปใช้**, กล่อง **ค่าที่อ่านกลับจากอุปกรณ์**

1. ดูค่าที่อ่านกลับก่อน จดไว้เป็นค่าเดิม
2. ปรับ **ความสว่างรวม** ลงเล็กน้อย (เช่น −10) กด **นำไปใช้** → ต้องเห็นข้อความ **ปรับความสว่างแล้ว** และจอมืดลงจริง
3. ลองปรับเกนทีละสี ดูว่าสีบนจอเปลี่ยนตรงสี (แดงเปลี่ยนแดง ฯลฯ)
4. **คืนค่าเดิม** แล้วกด **นำไปใช้**

> หมายเหตุ: ความสว่างไม่ต้องล็อกอินขั้นสูง ค่าที่ตั้งเป็นค่าชั่วคราวและหายเมื่อปิดไฟ (ถ้าโปรแกรมแจ้ง `ไม่มีสิทธิ์ ต้องเข้าสู่ระบบขั้นสูงก่อน` ให้จดไว้ด้วย)

**จดถ้าต่าง:** ค่าอ่านกลับไม่ตรงกับที่ตั้ง (บอกค่าที่ตั้งและค่าที่อ่านกลับ), จอไม่เปลี่ยน, สีสลับกัน, สเกลของตัวเลขต่างจาก NovaLCT (เช่น 100% ของ NovaLCT เท่ากับค่าอะไรในโปรแกรม)

## 6. ภาพทดสอบ (Test Patterns)

เมนู **ทดสอบและการแสดงผล** → ส่วน **ภาพทดสอบ**: **ปิด, แดง, เขียว, น้ำเงิน, ขาว, เส้นแนวนอน, เส้นแนวตั้ง, เส้นทแยง, เกรย์สเกล**

กดทีละปุ่ม ดูที่จอ LED แล้วจบด้วย **ปิด** เสมอ

**คาดว่า:** จอแสดงสี/ลายตามชื่อ และ **ปิด** กลับสู่ภาพปกติ

**จดถ้าต่าง:** ปุ่มไหนแสดงผิดสี/ผิดลาย (เช่น กด "เส้นแนวนอน" แต่ได้เส้นแนวตั้ง), ปุ่มไหนไม่มีผล, **ปิด** แล้วภาพไม่กลับ (ถ้าไม่กลับให้ปิด-เปิดไฟตัวควบคุม)

---

## 7. จอดำ / หยุดภาพ (ค่า byte ยังไม่ยืนยัน)

เมนู **ทดสอบและการแสดงผล** → ส่วน **โหมดการแสดงผล**: **ปกติ, จอดำ, หยุดภาพ**

ทดสอบ **ขณะมีวิดีโอเคลื่อนไหวเข้ามาที่ตัวควบคุม** (เช่น เปิดวิดีโอหรือเลื่อนหน้าต่างในจอคอมที่ส่งภาพมา) เพื่อให้เห็นความต่างของ "หยุดภาพ"

1. กด **จอดำ** → จอควรดับ (ภาพดำ) กด **ปกติ** → ภาพกลับ
2. กด **หยุดภาพ** → ภาพบนจอควรค้างทั้งที่ต้นทางยังเคลื่อนไหว กด **ปกติ** → กลับมาเคลื่อนไหว
3. ลองสลับ จอดำ → หยุดภาพ → ปกติ ต่อเนื่อง เพื่อดูว่าทั้งสองโหมดไม่ค้างติดกัน

ค่าที่โปรแกรมเขียนตอนนี้ (`DISPLAY_MODE_VALUES` ใน `packages/device/src/service.ts`):

| ค่า | ใช้ทำอะไร | ค่าปัจจุบัน |
|---|---|---|
| `killOn` | เปิดจอดำ (SetKillMode, รีจิสเตอร์ 0x02000100) | 1 |
| `killOff` | ปิดจอดำ | 0 |
| `lockOn` | เปิดหยุดภาพ (SetLockMode, รีจิสเตอร์ 0x02000102) | 1 |
| `lockOff` | ปิดหยุดภาพ | 0 |

**จดถ้าต่าง (สำคัญมาก):** จอดำทำงานหรือไม่ / หยุดภาพทำงานหรือไม่ / ทำงานแต่กลับเป็น "ปกติ" ไม่ได้ / จอดำแต่ได้ผลของหยุดภาพแทน (สลับกัน) / ผลเกิดกับการ์ดรับทุกใบหรือเฉพาะบางพอร์ต ถ้าหยุดภาพไม่ทำงาน ผู้พัฒนาจะลอง `lockOn = 2` (ตาม ControlModeType: Normal=0, Black=1, Lock=2) ซึ่งต้องแก้โค้ดแล้วสร้างตัวติดตั้งใหม่ ให้จดผลของค่าปัจจุบันไว้ก่อน

> ถ้าทดสอบแล้วจอค้างในโหมดจอดำ/หยุดภาพ และกด **ปกติ** ไม่หาย ให้ปิด-เปิดไฟตัวควบคุม

## 8. การ์ดส่ง (อ่านอย่างเดียวในขั้นนี้)

เมนู **การ์ดส่ง** (กด **รีเฟรช** เพื่ออ่านใหม่) ส่วน **สัญญาณขาเข้า** (**สัญญาณขาเข้า**: พบสัญญาณ / ไม่มีสัญญาณ, **ความกว้าง/ความสูง (พิกเซล)**, **อัตรารีเฟรช (ค่าดิบจากรีจิสเตอร์)**, **อัตราสัญญาณที่วัดได้ (ค่าดิบจากรีจิสเตอร์)**, **แหล่งสัญญาณ**), ส่วน **พอร์ตเอาต์พุตอีเทอร์เน็ต** (คอลัมน์ พอร์ต / เปิดใช้งาน / พื้นที่ที่โหลด / จำนวนพิกเซล / การ์ดรับ), ส่วน **สำรอง / รีดันแดนซี**

ขั้นนี้ **ห้ามกด นำไปใช้ใด ๆ** ให้ดูอย่างเดียว

**คาดว่า:** ความละเอียดตรงกับสัญญาณที่ป้อน (เช่น 1920×1080), สถานะสัญญาณถูกต้องเมื่อถอด/เสียบสายวิดีโอ, แหล่งสัญญาณตรงกับช่องที่เสียบจริง (ถ้าขึ้น "ไม่ทราบ (ค่าดิบ …)" ให้จดค่าดิบ), จำนวนพิกเซลต่อพอร์ตสมเหตุสมผล

**จดถ้าต่าง:** ความละเอียด/แหล่งสัญญาณผิด, ค่าดิบของอัตรารีเฟรชทั้งสองช่อง พร้อมอัตราจริง (เช่น 60 Hz → ค่าดิบ = ?) เพื่อใช้หาสูตรแปลงหน่วย, พอร์ตที่มีการ์ดแต่ไม่แสดง

## 9. การ์ดรับ (อ่านอย่างเดียว) และตรวจสอบสถานะ

### 9.1 การ์ดรับ

เมนู **การ์ดรับ** → เลือกจากรายการ **การ์ดรับ** (รูปแบบ "พอร์ต N / การ์ดที่ M (รุ่น)") → กล่อง **พารามิเตอร์ที่อ่านจากการ์ด** กด **อ่านใหม่** เพื่ออ่านซ้ำ

ดู: **ขนาดโมดูล (พิกเซล)**, **โหมดสแกน**, **กลุ่มข้อมูล (จริง / ตรรกะ)**, **กลุ่มข้อมูลต่อโมดูล**, **จำนวนแถวของโมดูล**, **ไอซีไดรเวอร์ (รหัส)**, **ตัวถอดรหัสแถว (รหัส)**, **จำนวนการรีเฟรชต่อเฟรม**, **ความลึกเกรย์สเกล (ค่าดิบ)**, **วิธีสร้างเกรย์สเกล**, **แกมมา (ค่าดิบจากรีจิสเตอร์)**, **อุณหภูมิ (ค่าดิบ)**, **แรงดันไฟ (ค่าดิบ)**

เปรียบเทียบกับค่าใน NovaLCT เดิม (เปิดดูได้ แต่อย่าให้ NovaLCT และ RockzaLCT เชื่อมพร้อมกัน) หรือกับสเปกโมดูล LED ที่ใช้

**จดถ้าต่าง:** ค่าที่ไม่ตรงกับ NovaLCT/สเปกโมดูล (ระบุชื่อช่อง, ค่าที่โปรแกรมแสดง, ค่าที่ถูก), ช่องที่ขึ้น **ไม่มีข้อมูล**, ขนาดโมดูล **กว้าง/สูงสลับกัน** หรือไม่, **ค่าแกมมาดิบ** เทียบกับแกมมาที่ตั้งใน NovaLCT (เช่น 2.8 → ดิบ = ?)

### 9.2 ตรวจสอบสถานะ (monitoring)

เมนู **ตรวจสอบสถานะ** (อ่านอย่างเดียว) เลือก **ช่วงเวลารีเฟรช** เช่น 5 วินาที หรือกด **รีเฟรชทันที** ดูสรุป **ออนไลน์ / ออฟไลน์ / คำเตือน / วิกฤต**, ตาราง **การ์ดรับ** ("พอร์ต N · การ์ด M", **อุณหภูมิ (ดิบ)**), **รายละเอียดการ์ด** (**อุณหภูมิ**, **ความชื้น**, **แรงดัน**, **บล็อกบิตผิดพลาด**, **การ์ดมอนิเตอร์ที่ต่อพ่วง**, **เตือนควัน**, **พัดลม**), ส่วน **การ์ดส่ง** (ลิงก์ ปกติ/บางส่วน/ขาด/ว่าง)

**ทดสอบเพิ่ม (ไม่ทำลายอะไร):** ถอดสาย Cat5 ระหว่างการ์ดรับหนึ่งใบแล้วรีเฟรช → การ์ดนั้นและใบถัดไปในสายควรเป็น **ออฟไลน์** / ลิงก์พอร์ตเป็น **บางส่วน/ขาด** แล้วเสียบกลับ → กลับเป็นปกติ

**จดถ้าต่าง:**
- **อุณหภูมิ (ดิบ) เทียบกับอุณหภูมิจริง:** เทียบกับค่าที่ NovaLCT แสดงในเวลาเดียวกัน จดคู่ (ค่าดิบ ↔ °C) อย่างน้อย 3 จุด (เช่นตอนเครื่องเย็น/อุ่น) และดูว่าค่าเป็น 0 หรือ 255 เสมอหรือไม่ (ลำดับ byte [valid, value] ของบล็อกอุณหภูมิ **ยังไม่ยืนยัน**)
- ความชื้น/แรงดันดิบ เทียบกับ NovaLCT
- การ์ดที่ออนไลน์อยู่แต่โปรแกรมบอกออฟไลน์ (หรือกลับกัน)
- สถานะพัดลม/ควัน ที่แสดงเตือนทั้งที่ปกติ

## 10. ผังการเชื่อมต่อจอ — อ่านจากฮาร์ดแวร์ (อ่านอย่างเดียว)

เมนู **ผังการเชื่อมต่อจอ** → ส่วน **ตัวควบคุม** กด **อ่านจากฮาร์ดแวร์** (ห้ามกด **ส่งลงฮาร์ดแวร์**)

**คาดว่า:** ข้อความ **อ่านผังจากตัวควบคุมแล้ว** และผังที่แสดงตรงกับการเดินสายจริง (ตู้แถว/คอลัมน์ไหนอยู่พอร์ตไหน ลำดับตู้) ถ้าตัวควบคุมไม่เคยตั้งผัง จะขึ้น **ตัวควบคุมยังไม่มีผังที่ตั้งค่าไว้**

กด **แสดงหมายเลขตู้บนจอ** เพื่อให้จอจริงโชว์หมายเลขตู้ (เทียบกับผังบนหน้าจอ) แล้วกด **ซ่อนหมายเลขตู้**

**จดถ้าต่าง (สำคัญ):**
- **ตำแหน่ง X/Y สลับกันหรือไม่:** ไลบรารีขัดแย้งกันเองเรื่องตำแหน่งการ์ด โค้ดตอนนี้ถือว่า byte 0–1 = Y และ byte 2–3 = X (`decodeScannerXY` ใน `packages/device/src/features/layout.ts`) ถ้าจอที่จัดเป็นสี่เหลี่ยมผืนผ้า (เช่น 4 คอลัมน์ × 2 แถว) แล้วผังที่อ่านออกมาเป็น 2 คอลัมน์ × 4 แถว หรือตู้ถูกสะท้อน/หมุน แสดงว่า X/Y สลับ — ถ่ายภาพผังบนโปรแกรมและภาพจอจริงที่แสดงหมายเลขตู้
- ข้อความ **การ์ดบนตัวควบคุมไม่เรียงเป็นตารางปกติ**, **การ์ดรับ N ใบยังไม่ได้ตั้งขนาด จึงข้ามไป** (จดค่า N)
- ลำดับหมายเลขตู้/ทิศทางเดินสาย ไม่ตรงกับของจริง

อย่าเพิ่งไปขั้นถัดไปถ้ายังไม่ได้ **สำรองค่า** ตามหัวข้อ 0 ข้อ 3

## ขั้นขั้นสูง (เสี่ยง: เขียนค่า) — ทำเมื่อผ่านขั้นก่อนหน้าและสำรองค่าแล้วเท่านั้น

> ทำบน **จอเล็ก/ชุดทดสอบ** และใช้ **การ์ดรับเพียงใบเดียว** ล็อกอินขั้นสูง (ปุ่ม **เข้าสู่ระบบขั้นสูง**, รหัส `admin`) แล้วแถบบนต้องขึ้น **ระดับ: ขั้นสูง**

## 11. เขียนค่าการ์ดรับ (การ์ดใบเดียว)

เมนู **การ์ดรับ** → เลือกการ์ดใบทดสอบ 1 ใบ **ตรวจให้แน่ใจว่าไม่ได้ติ๊ก "ใช้กับการ์ดรับทุกใบ (broadcast)"** → ส่วน **แก้ไขรีเฟรช แกมมา และเกรย์สเกล**

1. จดค่าเดิมของ **จำนวนการรีเฟรชต่อเฟรม**, **แกมมา**, **ความลึกเกรย์สเกล**, **วิธีสร้างเกรย์สเกล**, **โหมดเกรย์สเกล**
2. เปลี่ยนค่า **ทีละช่อง และเปลี่ยนน้อย ๆ** (เช่น แกมมาขยับเล็กน้อย) กด **นำไปใช้** → ต้องเห็น **ตั้งค่าการ์ดรับแล้ว**
3. กด **อ่านใหม่** ดูว่าค่าที่อ่านกลับตรงกับที่ตั้ง และดูจอว่าภาพเปลี่ยนจริงเฉพาะบริเวณของการ์ดใบนั้น
4. **คืนค่าเดิมทันที** กด **นำไปใช้**

**ห้ามใช้ "ไลบรารีโมดูล → ใช้กับการ์ด" ในขั้นนี้** เพราะเขียนทั้งขนาดโมดูล/สแกน/ไอซีหลายค่าพร้อมกัน ยกเว้นต้องการทดสอบแยกต่างหากบนการ์ดทดสอบที่ยอมให้เสียได้

**จดถ้าต่าง:** ค่าอ่านกลับต่างจากที่ตั้ง, ภาพเพี้ยน/กะพริบ/ดับ (ระบุค่าที่ตั้ง), เปลี่ยนแล้วกระทบการ์ดใบอื่น, หน่วยของแกมมาดิบเทียบกับ NovaLCT

## 12. บันทึกลงฮาร์ดแวร์ (ถาวร) + ทดสอบปิด-เปิดไฟ

เสี่ยงสุดของฝั่งการ์ดรับ เพราะเขียนแฟลช และ **ค่าคำสั่งบันทึกยังไม่ยืนยันกับเครื่องจริง** (`SAVE_COMMAND_VALUES` ใน `packages/device/src/features/persist.ts`: `sender = 1`, `receiver = 1`)

1. (ต้องมีไฟล์สำรองแล้ว) ทำขั้นที่ 11 ให้ค่าบนการ์ดทดสอบเปลี่ยนเป็นค่าที่ "ปลอดภัยและเห็นผลได้" เช่น แกมมาเปลี่ยนเล็กน้อย
2. เมนู **บันทึก/โหลด** → ส่วน **บันทึกลงฮาร์ดแวร์** → **บันทึกการ์ดใบไหน** เลือก **พอร์ต N / การ์ด M** ของการ์ดทดสอบ (**ไม่เลือก "การ์ดรับทุกใบ"**) และ **ไม่ติ๊ก "บันทึกการ์ดส่งด้วย"**
3. กด **บันทึกลงฮาร์ดแวร์…** → ยืนยันที่หน้าต่าง **บันทึกลงฮาร์ดแวร์?** ด้วย **ใช่ ดำเนินการต่อ** → ต้องเห็น **บันทึกการ์ดรับแล้ว 1 ใบ**
4. **ปิดไฟตัวควบคุม+จอ รอ 10 วินาที เปิดใหม่** เชื่อมต่อใหม่ แล้วเข้า **การ์ดรับ** → **อ่านใหม่**

**คาดว่า:** ค่าที่ตั้งยังอยู่หลังเปิดไฟใหม่ = บันทึกสำเร็จ (ค่า 1 ถูกต้อง) ถ้าค่ากลับไปเป็นค่าเดิม = คำสั่งบันทึกไม่ทำงานด้วยค่า 1

**จดถ้าต่าง:** โปรแกรมบอกสำเร็จแต่ค่าหายหลังปิดไฟ, error ระหว่างบันทึก (ข้อความ **บันทึกบางรายการไม่สำเร็จ**), จอผิดปกติหลังบันทึก
จากนั้น **คืนค่าเดิม แล้วบันทึกซ้ำให้ฮาร์ดแวร์กลับสู่สภาพเดิม** หรือโหลดไฟล์สำรอง (หัวข้อ 0 ข้อ 8)

ส่วน **การ์ดส่ง** (ติ๊ก **บันทึกการ์ดส่งด้วย**) ให้ทดสอบแยกเป็นรอบสุดท้าย และต้องเป็นค่าที่ไม่ได้เปลี่ยนแปลง (บันทึกค่าปัจจุบันซ้ำ) เท่านั้น

## 13. เขียนผังจอ บนจอเล็ก

ทำเมื่อขั้น 10 อ่านผังได้ตรงและมีไฟล์สำรองแล้ว **ใช้จอเล็กที่เดินสายง่าย (เช่น 2×2 ตู้)**

1. เมนู **ผังการเชื่อมต่อจอ** → **อ่านจากฮาร์ดแวร์** เพื่อเริ่มจากผังจริง
2. สร้างผังที่ **เหมือนของเดิมทุกประการ** ก่อน แล้วดูหัวข้อ **การตรวจสอบ** ต้องขึ้น **ผังถูกต้อง** กด **ส่งลงฮาร์ดแวร์** → ยืนยันในหน้าต่าง **ส่งผังลงตัวควบคุมหรือไม่** → **ส่งผัง** ต้องเห็น **ส่งผังแล้ว: N พอร์ต, M การ์ดรับ** และจอไม่เปลี่ยนจากเดิม
3. กด **อ่านจากฮาร์ดแวร์** อีกครั้ง ผังต้องเหมือนที่ส่ง
4. (ถ้ายังปลอดภัย) เปลี่ยนเล็กน้อย เช่น สลับรูปแบบเดินสาย (**รูปแบบการเดินสาย**) ส่งอีกครั้ง ตรวจด้วย **แสดงหมายเลขตู้บนจอ** ว่าตัวเลขบนจอจริงตรงกับผัง
5. ถ้าผิดพลาด: โหลดไฟล์สำรอง (**บันทึก/โหลด** → **เปิดไฟล์ตั้งค่าและนำไปใช้** → **เปรียบเทียบกับตัวควบคุม** → เลือก **ผังจอ** ใน **เขียนส่วนเหล่านี้** → **ใช้กับตัวควบคุม…**) หรือปิด-เปิดไฟ (ค่าที่ไม่ได้บันทึกแฟลชจะกลับมา)

**จดถ้าต่าง:** จอแสดงผิดตำแหน่งหลังส่ง, ผังที่อ่านกลับไม่ตรงกับที่ส่ง, **X/Y สลับ** (ดูขั้น 10), ข้อความ error ระหว่างส่ง, จอดับหลังส่ง
